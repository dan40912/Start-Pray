# Start Pray 公開體驗 UAT

本輪 UAT 範圍是公開信任、首訪路徑、首頁內容、禱告牆排序、全球代禱室，以及沉浸式 player。後台舊獎勵模組、Prisma schema、管理端與舊資料清理不在本輪。

## 建議安排

- UAT 時間：1 個工作天
- 驗收角色：PM、內容維護者、手機使用者代表、工程支援
- 測試環境：staging 或本機 production build
- 測試資料：至少 8 則公開代禱、2 則私密代禱、3 則有語音、3 則無回應、3 則文字回應、2 則語音回應、1 則匿名回應

## 入口條件

- `npm run lint` 通過
- `npm run build` 通過
- 測試環境可開啟 `/`、`/prayfor`、`/global-prayer-room`、`/prayfor/[id]`
- 測試帳號可登入並能送出文字回應

## 驗收情境

### 首頁

- 首屏可在 5 秒內理解 Start Pray 是禱告與陪伴平台。
- CTA 不會直接把未登入訪客推進困惑的建立流程。
- 新增說明段落語氣清楚、溫暖，不像舊產品頁或空泛行銷頁。
- 「熱門代禱」與「最需要禱告」切換後，卡片內容有明顯差異。
- 首頁底部數據只呈現公開、未封鎖、未被檢舉資料。

### 禱告牆

- `/prayfor` 預設顯示熱門排序。
- `/prayfor?sort=recent` 顯示最新排序。
- `/prayfor?sort=needsPrayer` 優先顯示回應較少、較新的代禱。
- 搜尋、分類、排序切換不互相卡住。
- 空狀態文字清楚指出下一步。

### 全球代禱室

- 地球預設以北半球視角開場，地球元素足夠大。
- 地球會緩慢自轉，使用者不用操作也能看見更多光點。
- 點光點後抽屜有三個主要入口：聆聽、留一句代禱、分享給小組。
- 沒有語音的光點會提示可以先留一句代禱。
- 手機抽屜不遮住主要操作，也不讓文字溢出。

### 沉浸式 Player

- 播放語音後進入沉浸畫面，留言跑馬燈出現在標題下方或中下段。
- 留言不遮住頭像、播放、暫停、關閉按鈕。
- 沒有文字留言時顯示安靜空狀態。
- 多首播放清單會聚合整個播放清單的文字留言。
- reduced motion 模式下跑馬燈停止動畫並改成靜態列表。

### 隱私

- 私密代禱不在公開頁露出 title、description、image、owner、detailsHref。
- 全球代禱室只顯示匿名大致位置光點，不公開私密細節。
- 被封鎖或被檢舉的回應不出現在 player 留言流與首頁統計。

## 出口條件

- P0/P1 問題數為 0
- 手機首頁、禱告牆、全球代禱室、詳頁 player 均可完成主要路徑
- PM 確認文案沒有舊獎勵產品敘事
- 內容維護者確認首頁新增段落可以正式公開
